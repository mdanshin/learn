# Неделя 16 — Резюме, отклики, собеседования

**Цель недели:** оформить позиционирование, резюме и подготовиться к интервью.

## Позиционирование

AI-assisted Full-Stack Developer · MVP Builder · Prototyping Engineer · React/TypeScript Developer
with AI workflow. Vibe Coding / AI Coding — как keyword, не как единственная идентичность.

## В резюме вынести

React · TypeScript · Supabase · PostgreSQL · Auth/RLS · Serverless functions (Edge/Vercel) · REST API ·
Webhooks · Payments · Telegram integration · LLM API · structured output + Zod · Cursor/Cline ·
AI-assisted development · MVP prototyping · GitHub Actions · Vercel · Vitest · migrations/generated types.

## Подготовка к интервью

- **2-минутный и 10-минутный** рассказ по каждому проекту.
- Ответы на вопросы: декомпозиция задачи для агента · проверка AI-кода · пойманные ошибки агента ·
  архитектура · как работает auth · как работает RLS · как проверяется webhook (idempotency/signature) ·
  как защищены secrets · payment flow · валидация LLM output через Zod · что улучшил бы при большем времени.
- **3–4 короткие live-coding задачи** на TS/React/forms/data fetching (не отдельный большой блок).
- Mock-интервью по Supabase RLS, auth, webhooks, LLM validation.
- Список компаний/ролей и адаптация резюме под них.

## Ресурсы

- [Tech Interview Handbook](https://www.techinterviewhandbook.org/) — структура подготовки.
- [Frontend Interview Handbook](https://www.frontendinterviewhandbook.com/) — React/JS вопросы.

## Критерий готовности (артефакт месяца)

- [ ] готовое резюме под целевые роли
- [ ] 2/10-мин питчи по проектам
- [ ] подготовлены ответы по auth/RLS/webhook/LLM/AI-review
- [ ] список вакансий/клиентов для отклика

> **Артефакт месяца 4:** готовое резюме + портфолио + список вакансий/клиентов для отклика.
