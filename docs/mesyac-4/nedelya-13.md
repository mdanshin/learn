# Неделя 13 — Утилита или бот (привязанная к портфолио)

**Цель недели:** собрать маленький законченный третий артефакт, который **усиливает** проекты №1/№2,
а не выглядит случайной игрушкой.

## Лучшие варианты

- Telegram-бот для создания лидов/заявок в проекте №2
- CLI для генерации weekly report из Supabase
- Google Sheets importer для проекта №1
- маленький webhook tester для собственного проекта

## Ресурсы

- [grammY — фреймворк для Telegram-ботов на TS](https://grammy.dev/).
- [Google Sheets API — Node.js quickstart](https://developers.google.com/sheets/api/quickstart/nodejs).
- [Создание CLI на Node](https://nodejs.org/api/util.html#utilparseargsconfig) — `util.parseArgs`.

## Практика

- Выбрать вариант, связанный с проектом №1 или №2.
- Собрать маленькую, но законченную утилиту.
- README + короткое демо.

## Критерий готовности (артефакт)

- [ ] проект маленький, живой, понятный за 30 секунд
- [ ] решает одну конкретную задачу
- [ ] связан с одним из основных проектов

> **Артефакт:** утилита №3 как дополнительный proof of speed, связанная с портфолио.
