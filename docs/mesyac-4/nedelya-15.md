# Неделя 15 — Упаковка портфолио

**Цель недели:** превратить проекты в кейсы, которые продают. Для найма сильная упаковка часто важнее
самой демки.

## Для каждого проекта

live demo · GitHub repo · README · screenshots · short demo video · architecture diagram (Mermaid) ·
список интеграций · security notes · AI-assisted workflow (что сделал агент, что проверял человек,
какие ошибки пойманы) · что бы улучшили дальше.

## Структура README

1. Проблема
2. Решение
3. Demo link
4. Видео
5. Стек
6. Основные фичи
7. Архитектура (Mermaid)
8. Интеграции
9. Безопасность
10. AI-assisted workflow
11. Как запустить локально
12. Env variables
13. Что улучшить дальше

## Ресурсы

- [Mermaid — диаграммы](https://mermaid.js.org/intro/) (GitHub рендерит их в README).
- [Awesome README](https://github.com/matiassingers/awesome-readme) — примеры сильных README.
- [Loom](https://www.loom.com/) / OBS — запись demo video.

## Критерий готовности (артефакт)

- [ ] 2 README + screenshots + live demos + short videos
- [ ] architecture diagram и security notes для каждого проекта

> **Артефакт:** портфолио-страница + 2 сильных кейса + 1 утилита.

:::note
Большие отдельные case-study документы — только если осталось время. Иначе достаточно сильных секций в README + одна диаграмма.
:::
