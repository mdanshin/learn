# Финальный набор портфолио

Три артефакта, каждый показывает свой навык.

## Проект №1 — Business CRUD / Internal Tool

**Mini CRM / Lead Tracker / Booking Dashboard.**
Показывает: React/TS · Supabase · Auth · RLS · CRUD · статусы/workflow · filters/search · dashboard ·
migrations + generated types · CI · deploy · README · clean UI.

## Проект №2 — Integration-heavy AI MVP

**AI Lead Processing Dashboard.**
Показывает: serverless backend boundary · external API · webhook + idempotency · Stripe test payment ·
Telegram notification · LLM API · structured output + Zod · event logging · dashboard · production thinking.

:::warning Граница переиспользования проектов №1 и №2
Переиспользуйте из проекта №1 **инженерный скелет** (Vite/TS setup, Tailwind/shadcn, auth-паттерн,
Supabase client, query/form/table паттерны, CI, структуру README). Но **домен, бизнес-объект,
интеграции и тип сложности обязаны быть другими** — иначе на найме это читается как один навык дважды.

- **Плохо:** «CRM» и «CRM с AI».
- **Хорошо:** «Booking dashboard» и «AI intake/payment pipeline».
:::

## Проект №3 — Small Utility / Bot

**Telegram bot / CLI report generator / Google Sheets automation.**
Показывает: скорость прототипирования · прикладную пользу · связь с основными проектами.
