# Как понять, что можно откликаться

Чеклист готовности. Можно начинать откликаться, если вы:

- [ ] собираете React/TypeScript MVP без ступора
- [ ] уверенно используете Supabase Auth, DB, RLS, migrations и generated types
- [ ] можете объяснить архитектуру своих проектов (включая backend boundary)
- [ ] подключили внешний API через serverless-функцию
- [ ] приняли и обработали webhook с idempotency
- [ ] реализовали test payment flow (Stripe) и проверяете подпись
- [ ] отправили Telegram-уведомление по событию
- [ ] встроили LLM API со structured output и Zod-валидацией
- [ ] держите все secrets server-side
- [ ] умеете читать и критиковать код агента, не принимаете AI diff вслепую
- [ ] имеете 2 живых **разных** проекта и 1 маленькую утилиту
- [ ] можете показать live demo и GitHub
- [ ] можете объяснить, где агент ошибался и как вы это поймали

## Реалистичный итог через 4 месяца

При 10 ч/нед и наличии прошлой базы реальная цель —
**junior+/middle-leaning AI-assisted prototyping developer**: быстро собирает MVP, безопасно
подключает интеграции через backend, работает с AI-агентами под контролем и доводит проект до
живого демо.

**Нереалистичная формулировка** — «уверенный full-stack developer за 160 часов с нуля».

Правильная ставка — не ширина стека, а способность показать: живой продукт · реальные интеграции
через безопасный backend · инженерную дисциплину (CI, tests, migrations, secrets) · контроль над
AI-агентом · понятное бизнес-применение.
