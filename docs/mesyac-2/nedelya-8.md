# Неделя 8 — Agent-assisted feature delivery

**Цель недели:** сделать профессиональный кейс — провести одну заметную фичу через агента по полному
циклу и задокументировать управление агентом.

## Формат кейса

1. Issue → 2. Спецификация → 3. Agent prompt → 4. Diff → 5. Human review notes → 6. Tests → 7. Deploy → 8. Краткое описание результата.

## Практика

- Добавить в проект №1 одну заметную фичу через агента (роли пользователей / CSV export / dashboard analytics / bulk actions).
- Написать `AI_WORKFLOW.md` **на реальном примере**: issue → prompt → diff notes → tests → результат.
- Зафиксировать 2–3 ошибки/риска, которые поймал человек.

## Ресурсы

- [Conventional Commits](https://www.conventionalcommits.org/) — опрятная история для кейса.
- [Пример структуры AI_WORKFLOW](https://agents.md/) — адаптируйте под свой процесс.

## Критерий готовности (артефакт месяца)

- [ ] проект №1 с новой фичей, проведённой через агента
- [ ] `AI_WORKFLOW.md` с реальным примером управления агентом
- [ ] зафиксированы пойманные человеком ошибки

> **Артефакт месяца 2:** проект №1 с новой фичей + документ `AI_WORKFLOW.md`.
