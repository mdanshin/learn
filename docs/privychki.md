# Постоянные привычки на весь период

Это не отдельная неделя, а фон, который держится все 4 месяца. Именно привычки отличают
«собрал демку» от «инженер, которому можно доверить прод».

- **Git с первого дня.** Каждый проект в Git, коммит после каждого осмысленного шага.
- **Работа через issue.** Каждый значимый кусок — через issue с чёткими границами.
- **Ревью каждого AI-diff.** Читаем по [review-чеклисту](/mesyac-2/nedelya-5). Никакого blind accept.
- **После AI-изменений всегда:** `lint` · `typecheck` · `tests` · `build`.
- **Секреты только в `.env` / serverless env.** В GitHub — `.env.example`, но не реальные ключи.
- **Схема БД — в migrations, типы генерятся.**
- **Каждый проект деплоится, CI зелёный.**
- **README пишется по ходу**, а не в последний день.
- **Короткий лог по AI:** что агент сделал хорошо · где ошибся · что пришлось переписать · чему научило.
- **Раз в неделю** — свежие материалы по Cursor/Cline/AI coding, но без прыжков на каждый новый инструмент.

:::tip
Эти привычки — то, о чём спрашивают на собеседовании под роль «AI-assisted». Умение
контролировать агента ценится выше, чем скорость генерации.
:::
